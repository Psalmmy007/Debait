CSV column help

Use headline_id,headline,draft_label,human_reference_label,review_status. Only headline is required. Common alternatives such as id, headline_text and expected_label are also accepted.

Draft labels are never treated as reviewed references. Set review_status to agreed only after human reviewers agree. Curiosity Gap, Uncertain, missing and disputed references are excluded from four-category agreement. Use UTF-8 comma-separated CSV; quote text containing commas.
